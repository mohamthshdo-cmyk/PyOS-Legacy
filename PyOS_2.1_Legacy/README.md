# PyOS Legacy (v2.1)

Legacy version of PyOS. **Superseded by [PyOS v2.2](https://github.com/mohamthshdo-cmyk/PyOS).**

Older, simpler codebase — kept for reference and comparison.

## Status

**Not maintained.** Use [PyOS v2.2](https://github.com/mohamthshdo-cmyk/PyOS) instead.

## What's different from v2.2

- No virtual disk (pyos/kernel/disk.py)
- No download manager (pyos/kernel/downloads.py)
- No File Explorer app
- Uses the Bliss wallpaper (pyos/system/bliss.py), removed in v2.2
- Some shell bugs fixed in v2.2

## Install

Python 3.9+, tkinter, `python main.pyw`
